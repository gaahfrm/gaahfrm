## About me

I'm a **Software Engineer with a Full Stack background**, currently working at **Irrah Tech** on the evolution of web products such as **Z-API, GPTMaker and Dispara Aí**.

My day-to-day work is mainly around **TypeScript, React, Next.js and Node.js**, but I also work across APIs, databases, integrations, performance and production environments when the problem requires it.

I enjoy owning problems end to end: understanding what needs to be built, turning it into a technical solution, shipping it and improving it after it reaches production.

- **Product engineering:** building features and web products from interface to backend and data.

## Selected projects

### [Compazio](https://github.com/gabriel-r-machado/compazio-releases)
Local-first desktop workspace for coordinating AI coding agents, real PTY terminals, notes, artifacts and Git workflows in the same canvas.

`Electron` `React` `TypeScript` `SQLite` `node-pty`

### [AgendaFlow](https://github.com/gabriel-r-machado/Agenda-Flow)
Multi-tenant scheduling SaaS designed around clear domain boundaries and production-oriented architecture, with **99% unit coverage on core business rules**.

`Next.js 16` `TypeScript` `PostgreSQL` `Supabase` `Jest` `Clean Architecture`

### [Distributed Ledger Core](https://github.com/gabriel-r-machado/Distributed-Ledger-Core)
Financial REST API built around consistency under concurrent transactions, using pessimistic locking, resilience patterns and integration testing.

`Java 21` `Spring Boot` `PostgreSQL` `Docker` `Testcontainers` `AWS`

### [AgentGuard](https://github.com/gabriel-r-machado/AgentGuard)
Open-source TypeScript framework for deterministic testing and behavioral scans of AI agents, with multi-provider execution and GitHub Actions support.

`TypeScript` `Node.js` `Zod` `GitHub Actions` `LLM APIs`
